# SMART WORKSPACE

A modern full-stack starter project with a React frontend and Express backend.

## Structure

- Client: [client](client)
- Server: [server](server)

## Scripts

- `npm install` installs all dependencies.
- `npm run dev` starts both the frontend and backend.
- `npm run dev:client` starts only the Vite frontend.
- `npm run dev:server` starts only the Express backend.
- `npm run build` builds the frontend for production.

## Default URLs

- Frontend: http://localhost:3000/
- Backend: http://localhost:5000/
